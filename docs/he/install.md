# התקנה - מה קורה, מה יורד, ועל מה עונים

> נכתב ב-2026-10-03. המתקין (`install/setup.py`) נבדק בבדיקות אוטומטיות עם הדמיות וב-CI על Windows, macOS ו-Ubuntu; הוא עדיין לא רץ על מחשב תלמיד נקי. ההוראות של הסוכן נמצאות ב-[INSTALL.md](../../INSTALL.md), והדף הזה הוא אותו תהליך בשבילך. אנגלית: [docs/en/install.md](../en/install.md).

**הריפו הזה מכין את Claude Code עצמו. הוא לא עוסק בעריכת וידאו.** העריכה באה אחר כך, מהריפו השני (`editing-workflow`).

## על מה תישאל
**שאלה אחת**, לפני ששום דבר משתנה: "להכין את שלושתם, או לדלג על חלק?" אפשר להוריד כל אחד מהשלושה. שום דבר אחר לא נשאל. אין חשבונות, מפתחות או תשלומים.

## מה מוגדר, ומה יורד
| # | מה | מה זה נותן לך | מה יורד | מה משתנה במחשב |
|---|---|---|---|---|
| 1 | **ברירות מחדל לעבודה** | בלוק קצר של כללים כלליים ב-`~/.claude/CLAUDE.md`: הקשר קטן (פחות קרדיטים), בדיקה אמיתית לפני "סיימתי", ברירות מחדל בטוחות ([למה כל כלל](working-defaults.md)) | כלום | בלוק מסומן אחד ב-`~/.claude/CLAUDE.md`; קודם נשמר גיבוי של הקובץ; הטקסט שלך אף פעם לא נוגעים בו |
| 2 | **Playwright MCP** | נותן ל-Claude Code לפתוח ולראות דפי אינטרנט בדפדפן מבודד בלי חלון | החבילה `@playwright/mcp@0.0.83` מ-npm בשימוש הראשון; ייתכן שדפדפן Chromium יורד בשימוש הראשון (הגודל לא נמדד) | שרת MCP אחד בשם `playwright` למשתמש שלך |
| 3 | **התוסף Superpowers** | אוסף סקילים לתכנון, דיבוג וסקירה | קבצי התוסף מהחנות הרשמית של Anthropic ב-GitHub | החנות הרשמית מתווספת אם היא חסרה, ואז התוסף מותקן למשתמש שלך; הוא נטען בפעם הבאה ש-Claude Code מופעל |
עלות: אפס. ביטול: `python install/setup.py uninstall --yes` מסיר בדיוק מה שנוסף.

| אתה | הסוכן |
|---|---|
| מדביק את הלינק, עונה על שאלת כן/לא אחת (ויכול לדלג על כל אחד מהשלושה) | משכפל את הריפו, מציג תוכנית, מגדיר את שלושת הדברים ובודק אותם |
| מתקין Node או Git בעצמך אם התוכנית אומרת שאחד חסר | מציג את הפקודה המדויקת; אף פעם לא מתקין אותם בשבילך |
| מפעיל מחדש את Claude Code בסוף | אומר לך מתי |

<!-- step: setup-01 -->
## setup-01 - פותחים את Claude Code ומדביקים את הלינק
פותחים את Claude Code בכל תיקייה, מדביקים את הלינק של הריפו וכותבים "תתקין את זה". אם כותבים בעברית, כל השיחה בעברית.

<!-- step: setup-02 -->
## setup-02 - הסוכן מוריד את הריפו
הוא משכפל את הריפו לתיקייה **באותיות אנגליות בלבד** (בלי עברית בנתיב) ומוצא Python שעובד. אין Git? הוא מציע להתקין Git או להוריד ZIP של אותו לינק, ואומר לך קודם את שם הקובץ והגודל.

<!-- step: setup-03 -->
## setup-03 - התוכנית (קריאה בלבד)
הפקודה `python install/setup.py plan` מראה, לכל אחד משלושת השלבים, מה זה, מה יורד, מה משתנה והאם צריך לענות על משהו. היא לא משנה כלום. אם חסר Node (בשביל Playwright) או Git (בשביל התוסף), היא מציגה את הפקודה ולא מתקינה בעצמה; אחרי שהתקנת, פותחים **טרמינל חדש**.

<!-- step: setup-04 -->
## setup-04 - מאשרים פעם אחת
הסוכן מסביר את שלושת השלבים במילים פשוטות ושואל שאלה אחת. זו הפעם היחידה שנשאלים.

<!-- step: setup-05 -->
## setup-05 - ההגדרה רצה
`python install/setup.py apply --yes`. כל שלב מדפיס שורה אחת. אם אחד נכשל, קוראים את השורה ומריצים שוב את אותה פקודה; שלבים שהסתיימו מדולגים.

<!-- step: setup-06 -->
## setup-06 - מפעילים מחדש ובודקים
הפקודה `python install/setup.py verify` מדפיסה עבר/נכשל לכל שלב. אחר כך **מפעילים מחדש את Claude Code**: תוספים ושרתים נקראים בהפעלה. בשיחה החדשה `/mcp` אמור להציג את `playwright`, ו-`claude plugin list` אמור להציג את `superpowers`.

<!-- step: setup-07 -->
## setup-07 - הבא בתור: ארגז הכלים לעריכה
מדביקים את הלינק של ריפו העריכה, <https://github.com/Malik-rgb43/editing-workflow>, ואומרים "תתקין את זה". הוא ישאל איך אתה רוצה לעבוד (מקומי, מחובר או שניהם) ולאילו שירותים אתה רוצה להתחבר.

<!-- step: setup-08 -->
## setup-08 - אם משהו נכשל
מריצים שוב את אותה פקודה. ראה [פתרון בעיות](troubleshooting.md). לביטול: [הסרה](uninstall.md). אף פעם לא שולחים מפתח כדי לקבל עזרה; שולחים את שורת השגיאה ואת `python install/setup.py verify --json`.

## שימוש ידני בלי סוכן
```text
git clone <repository link> "<ASCII folder>"
cd "<ASCII folder>"
python install/setup.py plan
python install/setup.py apply --yes
python install/setup.py verify
```
ב-Windows PowerShell 5.1 אין תמיכה ב-`&&`: פקודה אחת בכל שורה. עוטפים נתיבים במרכאות כפולות.
