# כללי חיסכון בקרדיטים - מה הם ולמה

> נכתב ב-2026-10-03. מקור: עמוד "Manage costs effectively" של Anthropic ל-Claude Code (https://code.claude.com/docs/en/costs). הכללים משנים את ההתנהגות של Claude Code ולא את התוכנית שלך, והחיסכון לא נמדד כאן - בדוק בעצמך עם `/usage`.

Claude Code שולח את כל השיחה בכל הודעה, ולכן הקשר קטן יותר עולה פחות. הבלוק שנוסף ל-`~/.claude/CLAUDE.md` (הטקסט נמצא ב-`templates/claude-md/credit-saver.md`) מבקש מ-Claude Code לעבוד כך:

<!-- step: saving-01 -->
## saving-01 - לשמור על הקשר קטן
מחפשים קודם וקוראים רק את השורות המתאימות; לא מדביקים פלטים ארוכים; לא קוראים שוב מה שכבר בשיחה; מציעים `/clear` כשהנושא מתחלף ו-`/compact` עם מה לשמור כשממשיכים. סוכן משנה (subagent) רק לעבודה בנפח גדול, אחד בכל פעם, על מודל קטן יותר.

<!-- step: saving-02 -->
## saving-02 - דברים קטנים ישר, דברים גדולים עם תוכנית קצרה
שגיאת כתיב, שינוי שם או שאלה נעשים ישר, בלי תהליכי תכנון. עבודה גדולה או לא ברורה מקבלת קודם תוכנית קצרה והסכמה שלך, וזה חוסך עבודה חוזרת יקרה. השינוי הקטן ביותר שמספק את הבקשה; שתיים עד ארבע שורות בסוף.

<!-- step: saving-03 -->
## saving-03 - כלים זולים והוכחות זולות
כלי שורת פקודה במקום שרת MCP נוסף כששניהם יכולים לעשות את העבודה; תמונת מצב טקסטואלית במקום צילום מסך בדפדפן; הבדיקה הרלוונטית האחת במקום כל הבדיקות.

<!-- step: saving-04 -->
## saving-04 - דברים שרק אתה שולט בהם
Claude Code לא ישנה אותם בעצמו, אבל יציע אותם: `/usage` (לראות מה צרכת), `/model` (מודל קטן יותר לעבודה שגרתית), `/effort` (נמוך יותר למשימות פשוטות), `/mcp` (לכבות שרתים שלא בשימוש), Esc ו-`/rewind` (לעצור מוקדם ולחזור אחורה). בבלוק יש גם "הוראות דחיסה" כדי שדחיסה תשמור את המטרה, ההחלטות, הקבצים והשגיאות.

הבלוק קצר בכוונה: הוא נקרא בכל הודעה, ו-Anthropic ממליצה לשמור את `CLAUDE.md` מתחת לכ-200 שורות. להסרה: `python install/setup.py uninstall --yes`, או למחוק את השורות שבין שתי הערות הסימון.
